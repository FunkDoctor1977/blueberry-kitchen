# Blueberry Kitchen 🫐

A gamified cooking and baking app for kids - designed by Rahmah (age 9).

Open the app: https://funkdoctor1977.github.io/blueberry-kitchen/

On a tablet: open the link in the browser, then 'Add to Home Screen' for the full app experience.
Grown-ups: add an AI key (optional) inside the app under My Badges -> Grown-ups' corner.
